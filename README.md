# Knowledge Vault

An [Obsidian](https://obsidian.md) vault for personal study notes. The main goal is to **read and take notes on landmark papers** in Machine Learning, Deep Learning and Computer Vision, plus the supporting concepts (biology, math, CS, philosophy) they rely on.

## Where the paper list comes from

The reading list in [`Papers/Landmark papers in Machine Learning, Deep Learning and Computer Vision.md`](<Papers/Landmark papers in Machine Learning, Deep Learning and Computer Vision.md>) was **generated by Gemini 3.1 Pro** and then **manually verified** (titles, authors, years, venues) before being used here.

The full roadmap (100 papers with DOIs, chronological and thematic) is available as a PDF: [`Papers/landmark_papers.pdf`](Papers/landmark_papers.pdf).

## Structure

| Folder | Contents |
|---|---|
| `Papers/` | Paper notes, grouped by theme (e.g. `Classical Machine Learning Foundations/`) |
| `Biology/` | Neuroscience and cell biology concepts |
| `Mathematics/` | Math notes |
| `Computer Science/`, `Electronics/` | CS and hardware concepts |
| `Concepts/` | Cross-cutting ideas (memory, reward, reinforcement learning…) |
| `Philosophy/`, `Physics/` | Supporting topics |
| `Books/`, `Movies/`, `Music/`, `Quotes/` | Other media notes |

Link concepts with `[[wikilinks]]` (e.g. `[[Neuron | neuron]]`) so the graph connects papers to the concepts behind them.

## Commit convention

Format: `<type>(<scope>): <summary>`: imperative, ≤50 chars, no trailing period. Add a body only when the *why* isn't obvious.

| Type | Use for |
|---|---|
| `paper` | New or updated notes on a paper |
| `note` | New or updated general notes (biology, math, books…) |
| `concept` | New concept note in `Concepts/` |
| `link` | Adding or fixing `[[links]]` between notes |
| `refactor` | Moving, renaming, reorganizing files/folders |
| `fix` | Typos, wrong facts, broken links |
| `docs` | README / repo docs |
| `chore` | `.gitignore`, Obsidian settings, housekeeping |

Examples:

```
paper(perceptron): add notes on Rosenblatt 1958
note(biology): add Neuron, Axon and Soma
link(papers): connect McCulloch-Pitts to Boolean algebra
refactor(papers): group papers by theme
fix(hubel-wiesel): correct publication year
chore: ignore Obsidian workspace state
```

Tips: commit one paper or topic at a time, and don't commit mid-edit while Obsidian is rewriting links (`alwaysUpdateLinks` is on, so renames touch other files). Enable the template with `git config commit.template .gitmessage`.
